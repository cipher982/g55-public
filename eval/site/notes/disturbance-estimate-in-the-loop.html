Correction, 2026-11-17, after an outside review. The first version of this note said the result confirmed the missing-state explanation, said one pull size was used, and gave the size of the effect as 85 against 27 failures of 132. Those three statements are corrected below, and the corrected text is marked where it changed. A test that holds the pull for the whole run is in the next note.

What was asked

The previous note reads the model's failure under a constant sideways pull as a missing state: nothing in the model accumulates a standing error. If that is right, a state added outside the model should fix most of the failures, where more correction gain and a retrained correction did not. The rule was written before the run.

What was done

  • Bench only. An estimate of the outside sideways pull is subtracted from the model's steering request. The estimate is the measured sideways acceleration minus what a truck model predicts for the steering applied, smoothed over half a second. The model file is unchanged.
  • Same windows, scorer and two pull sizes (0.40 and 0.60 m/s2, 66 runs at each) as the earlier steering-bound test. The first version of this note said one size was used. A run fails to come back when it ends more than 0.5 m from the model's own undisturbed run. The pull lasts 3.2 s of a 7.4 s run, and this is measured in the last second, 3.2 to 4.2 s after the pull has ended.
  • Two versions of the estimate: the truck model exact, and the truck model's steering gain 20% wrong. An exact model costs nothing when undisturbed by construction, so the wrong one is the honest test.
  • 33 windows from 7 drives, and 8 turn windows from 4 drives with the wrong-gain version. The first version called the 33 windows straight. They are not: 12 contain a turn of 10 to 34 degrees with no signal.
  • Rule set in advance: with the wrong model, failures fall from the shipped count with an interval by drive that excludes zero and by more than the raised-bound test's 20, and undisturbed driving on the turn windows is not more than 5 cm further from the driver's path.

Both parts of the rule held. Two deviations from the plan: the rule named a count pooled over four pull sizes, and two were run, so the rule was not run as written and the comparison is at those two sizes. The turn run failed twice when a shared graphics card ran out of memory, the partial output was discarded unread, and the third attempt completed.

Corrections after outside review

  • The measure does not test a missing standing correction. A model with feedback and no memory would hold a standing offset while the pull lasts and return after it ends. The count is taken after the pull has ended, so it measures a slow or lost return from an excursion of 2 to 4 m. The statement that the result confirms the explanation is withdrawn in that form.
  • Lost view of the road inflated the size. Only 64 of the 132 shipped pulled runs keep view coverage of 0.8 or more at every step, against 114 with the estimate. On the 44 runs at the 0.40 pull that are valid in both, the shipped model is 0.89 m off at the end of the pull and 0.35 m off four seconds later (median), so it is returning slowly. Runs not back within 0.5 m on those 44: 16 shipped, 2 with the estimate. That is the defensible size, not 85 against 27 of 132.
  • The test is close to circular. The estimate's truck model is the simulator's own truck model with one number changed, so delay, response and limits match exactly. Only a 20% gain error was tried, in the direction that under-cancels.
  • Part of the shipped failure is the bench's lateral controller, which adds roughly 15 to 21% to an outside sideways acceleration. The estimate cancels that as well.
  • No new mechanism. Rejecting a constant disturbance with an estimate is textbook control. openpilot's lateral controllers on real cars carry an integral term and a learned steering offset (stated from reading, not checked against source here), so comma's simulated failure would mostly not reach the road. It matters for a port without that term.

What it does not show

  • A better model. This is classical control with an expected sign: an integral-style state. The size of the effect is the information, not the idea.
  • Robustness. The pull is added as the same quantity the estimate measures, so the only mismatch tested is one 20% gain error. There is no sensor noise, measurement delay, road bank or tyre slip.
  • Other pull sizes or smoothing times. Two pull sizes and one smoothing time were run.
  • That every failure is fixed. 11 of 66 runs at the matching start offset still fail with the wrong model.
  • That the gain is all control. The failures here often end with little of the scene left to render, so part of the gain may be staying inside what the bench can draw.
  • Anything on a vehicle. Nothing was changed or run on one.
  • Outside confirmation of the first version. The review found the problems listed above.
