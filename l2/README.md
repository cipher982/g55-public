# L2 Preparation

High-level public notes about preparing an older, non-ADAS vehicle for future driver-assistance research.

The central design boundary is conservative:

- listen-only vehicle acquisition is useful desk and bench work;
- perception, planning, and actuation are separate concerns;
- any future transmit path needs an independent safety gate and explicit validation;
- desk, bench, and vehicle results must never be described as equivalent;
- no public document here authorizes road testing or vehicle actuation.

The detailed vehicle hazard analysis remains in the private workspace while the public architecture and safety reasoning are being shaped. This section will contain only material that stands alone without private maintenance state, wiring locations, network details, or live vehicle instructions.
